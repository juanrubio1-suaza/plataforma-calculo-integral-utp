¿Qué es un sólido de revolución?

Es un cuerpo tridimensional que se obtiene al girar una región plana alrededor de una recta llamada eje de revolución. La integral permite sumar las áreas de sus secciones para calcular el volumen.

En esta sección se trabajan los cinco tópicos de los talleres: secciones transversales conocidas, asociación de figuras 2D con sólidos, discos alrededor de una línea horizontal, arandelas alrededor de una línea horizontal y sólidos alrededor de una línea vertical.

Cómo explorar: cambia los controles, pulsa el botón de cálculo y usa el mouse sobre las gráficas 3D para girar, acercar y observar el sólido desde diferentes ángulos. Los ejemplos son modelos didácticos; cada resultado muestra las dimensiones y la integral utilizada.

1. Volumen con sección transversal conocida (eje X)

Cuando se conoce el área de cada sección perpendicular al eje X, el volumen se obtiene integrando esa área: V = ∫ₐᵇ A(x) dx.

Usaremos como región base la anchura s(x) = √x en el intervalo [0, 4]. Puedes cambiar la forma de las secciones transversales.

3. Sólido alrededor de una línea horizontal (método de discos)

Al girar la región bajo y = √x, desde x = 0 hasta x = 4, alrededor del eje horizontal y = 0, se forman discos sin agujero.

Fórmula: V = π ∫₀⁴ [R(x)]² dx.

4. Sólido sobre una línea horizontal (método de arandelas)

Cuando la región no llega hasta el eje de giro, aparece un hueco interior. Se resta el área del disco pequeño a la del disco grande.

Fórmula: V = π ∫ₐᵇ [R(x)² − r(x)²] dx.

Ejemplo: girar la región comprendida entre y = 2 y y = 1, para 0 ≤ x ≤ 3, alrededor del eje horizontal y = 0.

5. Sólido sobre una línea vertical

Al girar una región alrededor de un eje vertical, conviene describir los radios en función de y e integrar respecto a esa variable.

Ejemplo: la región entre x = 0 y x = √y, para 0 ≤ y ≤ 4, gira alrededor del eje vertical x = 0. Se forman discos horizontales.

Fórmula: V = π ∫₀⁴ [R(y)]² dy.
