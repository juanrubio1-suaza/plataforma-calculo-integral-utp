Módulo 13: Integración de Trinomios ax² + bx + c

← Volver al Menú Principal

Marco teórico

Para integrar el recíproco de un trinomio cuadrático se analiza el discriminante Δ = b²−4ac. Según su signo, la respuesta involucra una función arcotangente, un logaritmo o una expresión racional.

Fórmula principal: ∫ dx/(ax² + bx + c)

Ingresa los coeficientes a, b y c. Se requiere a distinto de cero.

Calculadora interactiva

Selecciona el tipo de integral e ingresa los valores para obtener una antiderivada.

Visualización gráfica

Explora la curva del integrando. Puedes acercar, alejar y mover la gráfica. El área sombreada representa una región ilustrativa entre x = −2 y x = 2 (ajustada al dominio).

Recomendación de estudio

Antes de aplicar la fórmula, identifica la estructura del integrando y verifica las restricciones de dominio. Después, deriva el resultado para comprobar que recuperas la función original.
